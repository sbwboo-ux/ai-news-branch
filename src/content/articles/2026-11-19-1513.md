## 한눈에 보기
- AWS가 서버리스 환경에서 인프라 관리 없이 대규모 전면 파인튜닝(FFT)을 수행할 수 있는 기능을 제공합니다.
- 구글 딥마인드가 장기 소프트웨어 엔지니어링 및 지식 업무 처리에 최적화된 '제미나이 4 네온(Gemini 4 Neon)'을 공개했습니다.
- 래딕스아크(RadixArk)는 단 1,200개의 선별된 과제와 효율적인 강화학습 기법으로 성능을 끌어올린 오픈소스 모델 '데이지로즈-27B(DaisyRose-27B)'를 선보였습니다.

## AWS: 인프라 관리 없는 전면 파인튜닝(FFT) 지원

**무엇이 발표됐나**  
AWS는 아마존 세이지메이커 AI 서버리스 모델 커스터마이제이션(Amazon SageMaker AI Serverless Model Customization)에서 전면 파인튜닝(Full Fine-Tuning, 이하 FFT)을 지원한다고 밝혔습니다. 파인튜닝(Fine-tuning)이란 이미 학습된 기본 모델에 특정 분야나 기업의 데이터를 추가 학습시켜 목적에 맞게 조정하는 과정입니다. 기존에는 연산 자원을 아끼기 위해 모델 매개변수의 일부만 갱신하는 LoRA(Low-Rank Adaptation) 방식을 주로 활용했으나, 이제는 GPU 클러스터 구성이나 분산 학습 설정 없이도 모델 전체 매개변수를 갱신하는 FFT를 서버리스 방식으로 수행할 수 있게 되었습니다.

**무엇이 달라지나**  
데이터셋 규모가 수만 건 이상으로 커지고 작업이 복잡해질 때 LoRA 방식이 겪던 표현력 한계가 해소됩니다. AWS 실험에 따르면 11만 건의 코딩 지시 데이터셋을 바탕으로 Qwen3-4B 모델을 학습시켰을 때, 10만 건 이상의 데이터 구간에서 FFT는 거대언어모델 판정(LLM-as-Judge) 의미적 정확도 90.0%를 기록하며 LoRA 대비 우수한 성능을 보였습니다. 개발자와 데이터 사이언티스트는 복잡한 하드웨어 용량 계획 없이 기본 모델, 데이터셋, 하이퍼파라미터만 지정하여 고품질 특화 모델을 구축할 수 있습니다.

## 구글 딥마인드: 업무 실행에 집중한 제미나이 4 네온

**무엇이 발표됐나**  
구글 딥마인드는 복잡한 소프트웨어 엔지니어링, 지식 업무, 과학 연구 워크플로를 빠르게 완수하도록 설계된 프론티어급 인텔리전스 모델 '제미나이 4 네온(Gemini 4 Neon)'을 발표했습니다. 이 모델은 100만 토큰의 문맥 창(Context Window, 모델이 한 번에 처리할 수 있는 텍스트 단위)을 제공하며, 입력 토큰 100만 개당 3달러(캐시 적용 시 95% 할인된 0.15달러), 출력 토큰 100만 개당 15달러로 책정되었습니다.

**무엇이 달라지나**  
사용자 수정 지시에 맞춰 경로를 변경하는 유연성(Steerability)과 다단계 지시 이행 능력이 강화되었으며, 구글 안티그래비티(Google Antigravity) 내부 테스트 기준 가장 낮은 정보 왜곡(허위 생성) 비율을 보였습니다. 벤치마크 평가에서도 인공지능 분석 코딩 에이전트 지수(Artificial Analysis Coding Agent Index) 1위(58.6점), 발스 지수(Vals Index) 2위(70.9%)를 기록했습니다. 특히 사용자의 지출 예산과 작업 복잡도에 따라 연산 깊이를 조절할 수 있도록 4단계의 '생각 수준(thinking levels)'을 지원하여 운영 비용을 통제할 수 있습니다.

## 래딕스아크: 1,200개 과제로 입증한 사후 학습 효율 '데이지로즈-27B'

**무엇이 발표됐나**  
래딕스아크는 Qwen3.8-27B를 기반으로 강화학습(Reinforcement Learning, 보상을 통해 행동을 최적화하는 학습 방식) 프레임워크인 '마일스(Miles)'를 적용해 훈련한 '데이지로즈-27B(DaisyRose-27B)'를 아파치 2.0 라이선스로 공개했습니다. 144대의 H200 GPU를 활용해 18일 동안 학습을 마쳤으며, 훈련에는 단 1,200개의 엄선된 과제가 사용되었습니다.

**무엇이 달라지나**  
방대한 데이터 대신 모델이 자주 실수하는 지점을 타깃으로 정교하게 설계된 소수의 장기 실행 과제를 투입해 성능을 끌어올렸습니다. 그 결과 터미널 환경 평가 벤치마크인 '터미널-벤치 4.1(Terminal-Bench 4.1)' pass@1 점수가 기존 5.6%에서 12.0%로 대폭 개선되었고, 코딩 및 추론 벤치마크 전반에서 원본 모델을 상회했습니다. 아울러 에이전트 실행과 학습을 비동기로 분리한 내부 백엔드를 적용해 기존 메가트론 기반 학습 대비 GPU 소요 시간을 57% 절감하고 속도를 2배 높였습니다.

## 왜 중요한가

최근 AI 업계의 관심은 단순히 기본 모델의 덩치를 키우는 단계를 넘어, 실제 실무 환경에서 작동하는 모델을 얼마나 합리적인 비용과 높은 신뢰도로 확보하느냐로 옮겨가고 있습니다.

AWS의 서버리스 FFT는 인프라 관리 부담을 없애 기업이 자체 데이터의 가치를 모델 전체에 온전히 흡수시킬 수 있도록 돕습니다. 구글의 제미나이 4 네온은 작업 중간 개입 수용력과 긴 문맥 제어력을 내세워 복합 소프트웨어 개발 현장에 즉시 투입 가능한 에이전트 환경을 공략합니다. 동시에 래딕스아크의 성과는 대규모 인프라나 무차별적 데이터 수집 없이도 세심하게 설계된 1,200개의 과제와 고효율 강화학습 구조만으로 에이전트 성능을 두 배 이상 끌어올릴 수 있음을 증명합니다. 인프라 추상화, 실무 작업 최적화, 사후 학습 효율화라는 세 흐름이 맞물려 AI 도입의 장벽을 낮추고 있습니다.

## 앞으로 지켜볼 점
- 대규모 데이터 환경에서 LoRA를 대체하는 서버리스 FFT가 기업용 특화 모델 구축의 기본 표준으로 자리잡을지 주목됩니다.
- 제미나이 4 네온과 같이 세부적인 사고 단계 조절 기능과 낮은 왜곡률을 갖춘 모델이 실제 기업 소프트웨어 개발 생산성에 미치는 영향입니다.
- 래딕스아크가 제시한 정밀 과제 기반의 비동기 강화학습 기법이 오픈소스 진영의 사후 학습(Post-training) 비용 구조를 얼마나 빠르게 개선할지 지켜볼 필요가 있습니다.
